The site automatically grades IELTS Reading and Listening tests with exactly 40 questions. Other question counts are saved as ungraded practice. Writing has 2 tasks for manual review.

File format guide
  1. Exam paper For Reading and Listening, upload a DOCX, PDF or HTML file with passages, section headings and numbered questions. Scanned pages are supported. Check the recognized text in Preview test and edit any mistakes before starting.
  2. Answer key Upload the matching PDF, DOCX, HTML or TXT file. Put one numbered answer per line, such as 1. London. Separate accepted alternatives with |, such as 2. 35 | thirty five. A saved HTML results page must include the correct answers. For Writing, upload a separate PDF, JPG/JPEG or PNG for each task, or paste a screenshot into each task box.
  3. Listening audio Upload one full recording or four files in part order. Use Part 1 for questions 1–10, Part 2 for 11–20, Part 3 for 21–30 and Part 4 for 31–40. Linked audio in an HTML paper can also be used.

Tip — prepare your files with AI Upload your original paper and answer key to your AI assistant, then paste the prompt below. A selectable-text DOCX with clear numbering is easier to read accurately. Compare the exported files with your originals before uploading them here.

Example prompt to copy

Copy the text between the quotation marks below.

"Convert the attached IELTS paper and answer key into two separate files for an exam website.

1. Create an exam-paper DOCX with selectable text. Preserve all original wording, instructions, passages, tables and question numbers. Preserve diagrams as images. Read scanned text carefully and flag anything unclear instead of guessing.

2. Put each section heading on its own line. For Listening, use Part 1, Part 2, Part 3 and Part 4, with questions 1–10, 11–20, 21–30 and 31–40. For Reading, use Reading Passage 1, Reading Passage 2 and Reading Passage 3.

3. Put each question-group heading on its own line, for example “Questions 1–6”. Keep each question number with its question. For completion questions, keep the number and dotted blank inside the sentence, for example “The 1 ............ of London increased rapidly.”

4. Put each multiple-choice option on its own line, labelled A, B, C or D as printed. Put every entry in a matching list on its own line. Keep passage labels A, B, C and so on on separate lines before their paragraphs.

5. Create a separate answer-key TXT file, with one numbered answer per line, for example:
1. litter
2. dogs
Use | only for accepted alternatives to the same answer. Preserve “either order” pairs, for example “15&16. A | D”. For Writing, export separate Task 1 and Task 2 PDFs.

Keep the original question count and answers. Flag missing or unreadable content for me to check. Return both downloadable files."
